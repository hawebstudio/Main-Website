# Neon

## Overview

Neon is a serverless PostgreSQL platform that separates storage and compute, allowing databases to scale automatically, and even pause entirely during periods of no activity to save cost, while still providing the reliability and features of standard PostgreSQL underneath.

## What Is Neon?

Neon is a serverless PostgreSQL platform that separates storage and compute, allowing databases to scale automatically, and even pause entirely during periods of no activity to save cost, while still providing the reliability and features of standard PostgreSQL underneath.

At HA Web Studio, Neon is a database hosting option we use for projects that want PostgreSQL's reliability with a modern, serverless operating model, particularly for applications hosted on Vercel.

## Why We Use Neon at HA Web Studio

- Full PostgreSQL compatibility with a modern, serverless operating model
- Automatic scaling that matches your application's actual usage
- Database branching for safely testing changes before applying them
- Cost-efficient for applications with variable or unpredictable traffic
- No manual server provisioning or maintenance required

## How Neon Helps Your Business

For growing or seasonal businesses, a fixed-cost, always-on database can mean paying for capacity you don't consistently need. Neon's serverless model scales with actual usage, which keeps hosting costs proportional to your real traffic rather than a worst-case estimate.

Database branching, being able to create an isolated copy of your database schema and data to safely test a change, also reduces the risk of database-related issues affecting your live application, since changes can be validated in an isolated environment first.

## Neon Use Cases We Build

- PostgreSQL hosting for Next.js applications on Vercel
- Applications with variable or seasonal traffic patterns
- Projects needing safe database branching for testing changes
- Cost-efficient hosting for growing applications
- Any project using Prisma with PostgreSQL that wants a serverless deployment model

## Neon + Our Stack

Neon typically serves as the PostgreSQL host for applications using Prisma for data access, deployed alongside Next.js applications on Vercel, giving a fully serverless architecture from frontend to database.

## Frequently Asked Questions

**Is Neon as reliable as traditional PostgreSQL hosting?**
Yes, it's built on standard PostgreSQL underneath; the serverless model changes how it's operated and billed, not the underlying database engine's reliability.

**Will our costs be unpredictable with a serverless database?**
Costs scale with actual usage, which for most businesses is more predictable and often lower than paying for a fixed-capacity server year-round.

**Can we migrate away from Neon later if needed?**
Yes, since it's standard PostgreSQL, your data remains portable to any other PostgreSQL hosting provider if needed.
