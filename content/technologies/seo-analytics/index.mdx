# SEO & Analytics

## Introduction

This category covers the tools used to measure how a site performs and to help search engines
understand and index it correctly. Google Search Console and Bing Webmaster Tools are the
direct channels for seeing how each search engine actually crawls and indexes a site, including
errors that wouldn't be visible from the site itself. Google Analytics 4 and Microsoft Clarity
cover user behavior — GA4 for traffic, conversion, and audience data; Clarity for session
recordings and heatmaps that show how people actually use a page. Lighthouse audits a page for
performance, accessibility, and SEO issues using automated, repeatable scoring. Schema.org
structured data (JSON-LD) is the markup that gives search engines and AI systems explicit,
machine-readable facts about a page's content rather than requiring them to infer it from text.

## When These Technologies Are Used

Search Console and Bing Webmaster Tools should be set up on every indexable site — without
them, indexing errors can go unnoticed for months. GA4 is standard for any commercial site
where understanding traffic and conversion behavior matters; Clarity is added when the team
wants to see *why* a metric moved (a confusing form, a broken interaction), not just that it
did. Lighthouse is run during development and before launch to catch performance and
accessibility regressions before they reach users. Structured data is added specifically to
pages where it adds real, verifiable value — service pages, articles, FAQs, local business
information — never fabricated to game rich-result eligibility, per this project's own rule
against manipulated schema.
