# GitHub

## Overview

GitHub is a cloud platform for hosting and collaborating on code built with Git. It stores your project's complete codebase and history, supports collaborative review of changes before they're merged, and connects directly to automation tools like GitHub Actions for testing and deployment.

## What Is GitHub?

GitHub is a cloud platform for hosting and collaborating on code built with Git. It stores your project's complete codebase and history, supports collaborative review of changes before they're merged, and connects directly to automation tools like GitHub Actions for testing and deployment.

At HA Web Studio, GitHub is where every project's code lives, giving you full visibility and ownership of your website's codebase, not just the final live product.

## Why We Use GitHub at HA Web Studio

- Full ownership and access to your website's complete codebase
- Collaborative code review before changes go live
- Direct integration with automated testing and deployment pipelines
- Issue tracking for organizing bugs, features, and project tasks
- Industry-standard platform, easy to hand off to another developer if ever needed

## How GitHub Helps Your Business

Owning your codebase, not just having it exist somewhere, matters for the long-term flexibility of your website. With your project hosted on GitHub, you're never dependent solely on one agency or developer; the complete code and its history belong to you and can be handed to anyone else if needed.

GitHub's review and issue-tracking tools also keep development organized and transparent, you can see exactly what's being worked on, what's been completed, and what changed in any given update.

## GitHub Use Cases We Build

- Hosting the complete codebase for your website or application
- Organizing feature requests, bugs, and project tasks
- Reviewing code changes before they're deployed live
- Connecting to automated testing and deployment via GitHub Actions
- Providing a clear, transparent record of project progress

## GitHub + Our Stack

GitHub is the central hub connecting Git version control, GitHub Actions for automated testing and deployment, and the actual codebase for every Next.js, Node.js, and WordPress project we deliver.

## Frequently Asked Questions

**Do we own our GitHub repository?**
Yes, we typically set up the repository under your organization's account, or transfer ownership to you upon project completion.

**Can we see what's being worked on in real time?**
Yes, GitHub's issue tracking and project boards give visibility into current progress and completed work.

**What happens to our code if we stop working with HA Web Studio?**
Since you own the repository, your complete codebase and its history remain fully accessible to you or any future developer.
