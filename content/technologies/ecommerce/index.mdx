# Ecommerce

## Introduction

This category covers both the commerce platforms that manage products, inventory, and
checkout, and the payment gateways that actually process transactions. Shopify is a hosted,
managed ecommerce platform suited to store owners who want a proven system with minimal custom
engineering. Shopify Hydrogen is Shopify's headless framework for building a fully custom
storefront on Next.js/React while still using Shopify's backend for products, inventory, and
checkout — useful when a brand needs design freedom Shopify's standard themes can't offer.
WooCommerce adds ecommerce functionality on top of WordPress, for stores already built on that
platform. Stripe and Razorpay are payment gateways — Stripe with strong global card and
subscription support, Razorpay built specifically for the Indian market with support for UPI,
net banking, and other locally preferred payment methods.

## When These Technologies Are Used

Shopify (standard) fits store owners who want to launch quickly and manage the store themselves
without ongoing developer involvement. Hydrogen fits brands that need a fully custom storefront
design or performance beyond what Shopify's theme system supports, while keeping Shopify's
commerce backend. WooCommerce is chosen when a client already runs WordPress and wants
commerce added without migrating platforms. On payments, Razorpay is generally the stronger
default for an India-focused store because of UPI support and local payment method coverage,
while Stripe suits stores serving an international customer base or needing subscription
billing.
