# Shared Scripts

Shared TypeScript utilities for V1 build scripts.

Inputs: project files under `content/`, `app/`, `public/`, and config files.

Outputs: helper return values only.

Usage: import `toolkit.ts` from executable scripts.

Scripts: no direct CLI scripts live here.

Dependencies: Node.js and `gray-matter`.

Future expansion: CI-aware logging, config loading, structured JSON schemas, and provider adapters.
